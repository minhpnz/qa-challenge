# QA Automation Challenge

# Purpose

This task is designed to evaluate your capability in handling test case documentation, architecting a scalable end-to-end automation framework, and showcasing hands-on automation proficiency.

# Challenge **Overview**

### **Test Case Documentation**

Review the Login and Cart features of the application at https://www.demoblaze.com/.

Develop a well-rounded suite of test cases for these functionalities, covering:

- Functional scenarios
- Edge cases
- Negative paths

Document your test cases clearly using excel or google sheet.

### **End-to-End Automation Framework**

Outline and build a straightforward E2E test automation framework utilizing a modern testing tool such as **Playwright** (preferred), **Cypress**, or an equivalent with TypeScript

Your framework should incorporate:

- Cross-browser/platform support
- Modular design for ease of updates and scalability
- CI/CD compatibility (Jenkins, GitHub Actions, GitLab CI, etc.) for automated execution
- Configurable parameters and comprehensive reporting
- Support for automating different test types: UI, API, regression, performance

### **Automation Implementation Demo**

Create a basic automation demo targeting the following actions on the DemoBlaze site:

- Logging in with valid credentials
- Add to cart then place an order

Ensure that your test scripts include appropriate validations and handle both typical and edge case scenarios gracefully.

# **Deliverables (What to Submit)**

### **1. Test Case Suite**

- A thorough collection of test cases for Login and Cart modules
- Format: excel or google sheet

### **2. Automation Framework & Demo Automation Scripts**

- A functioning test framework
- Scripts that cover the Login and Cart use cases
- Format: via GitHub
  - Make your repo public
  - Include your repo link in the email

### **3. Documentation**

- A **README** file detailing:
  - Framework structure and rationale
  - Steps to execute the demo scripts
